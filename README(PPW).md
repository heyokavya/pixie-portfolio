# Pixie Portfolio

My personal portfolio website: Beyond Potential. Still Becoming.

Live site: https://iconic.heyokavya.workers.dev

## What's inside

- `index.html` is the whole website (HTML, CSS and JavaScript in one file, photos included)
- `og-image.jpg` is the preview picture shown when the link is shared
- `apple-touch-icon.png` is the icon for iPhone home screens

## How to edit

1. Open `index.html` in a text editor.
2. Change the text or a link.
3. Open the file in a browser to check it.
4. Upload or push the new version.

The file must always be named `index.html`.
